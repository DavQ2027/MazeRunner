# MakeRunner

MakeRunner es un proyecto de un videojuego de laberintos 2D  creado por estudiantes de 2º año de ¡Superate! utilizando tecnologias como HTML, CSS, Phaser y Javascript.

## Primera Pre-Version

Se añaden las carpetas esenciales, archivos HTML y JavaScript,
Se añade la configuración del juego,
Aun no hay jugabilidad.

## Ver 1.0

Se hacen las escenas del juego, se incorpora la logica de la jugabilidad y la jugabilidad del juego,
se añaden imagenes y la carpeta SRC para organizar las escenas del juego.
